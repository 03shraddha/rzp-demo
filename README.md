# rzp x ai

Live site: https://03shraddha.github.io/rzp-demo

A three-tab strategy demo built for the Razorpay AI interview.

| tab | what it does |
|-----|-------------|
| **razorpay docs mcp** | knowledge MCP server that gives AI agents accurate, up-to-date Razorpay API docs via BM25 search across 2,200+ pages |
| **payment recovery** | webhook-driven pipeline that detects payment failures and fires SMS, email, and Slack alerts in parallel within 10 seconds |
| **ai opportunity map** | filterable map of AI opportunities across Razorpay, J.P. Morgan, and CRED, with per-employee pain points and solutions |
